Detailed Description

PdfTemplateQuery class.

PdfTemplateQuery evaluates action-style filters against PDF objects. A filter can be defined as an ECMAScript regular expression or as a template hook configuration (for example tag_update, font_update, object_update, or annot_update) using the same JSON format as action parameters.
